# Sobre o Francos System Monitor

Francos System Monitor é um monitor de hardware para a Ubuntu Dock que reúne CPU, GPU, RAM e VRAM em um único ícone. O resumo ao passar o mouse acompanha os sensores em tempo real. Um clique abre um painel compacto com utilização, temperaturas e históricos.

O projeto prioriza baixo consumo de recursos. Seu coletor é compilado em C, a interface usa GJS dentro do GNOME Shell e as preferências GTK4/Python abrem sob demanda.

A primeira versão foi validada no Ubuntu 26.04.1, GNOME Shell 50.1, Wayland e uma GPU AMD com amdgpu. A compatibilidade detalhada, os limites da validação e as instruções de instalação estão no README.
